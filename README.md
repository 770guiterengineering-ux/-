# 有料note販売プロジェクト｜月商30万円達成計画

## 🎯 プロジェクトゴール

**月商30万円を有料note販売で達成する**

### 売上シミュレーション（いずれかの組み合わせで到達）

| モデル | 単価 | 必要販売数/月 | 備考 |
|---|---|---|---|
| 単発note（低単価） | 500円 | 600部 | 拡散力が必要 |
| 単発note（標準） | 1,000円 | 300部 | バランス型 |
| 単発note（中単価） | 3,000円 | 100部 | 専門性・実績が必要 |
| 単発note（高単価） | 5,000〜10,000円 | 30〜60部 | ノウハウ系・濃い読者向け |
| 月額マガジン（サブスク） | 980円 | 継続306人 | ストック型で安定しやすい |
| ハイブリッド | 単発＋マガジン混合 | 上記の組み合わせ | 実践的にはこれが現実的 |

初期は「単発note（標準〜中単価）＋マガジン」のハイブリッドを推奨。詳細は `04_価格戦略部/価格設定シート.md` で設計する。

## 🏢 部署構成（フォルダ構成）

一人プロジェクトでも「部署」単位でタスクを分けることで、抜け漏れなく運営できるようにしている。

```
.
├── 01_企画部/          … 何を売るか、誰に売るかを決める
├── 02_執筆部/          … note本文の制作
├── 03_マーケティング部/ … 集客・拡散導線の設計
├── 04_価格戦略部/       … 価格設計・商品ラインナップ
├── 05_販売分析部/       … 売上管理・KPI・振り返り
├── 06_顧客対応部/       … 購入者対応・レビュー管理
└── 07_運営管理部/       … スケジュール・タスク管理
```

## 🔄 運用フロー

1. **企画部**でネタ・ペルソナ・コンセプトを固める
2. **価格戦略部**で商品ライン（単発／マガジン／セット）を決める
3. **執筆部**で執筆・推敲し、公開する
4. **マーケティング部**の導線でnoteへ流入させる
5. **販売分析部**で毎週・毎月の数字を記録し、KPIを追う
6. **顧客対応部**で購入者の声を拾い、次の企画にフィードバックする
7. **運営管理部**で全体スケジュールとタスクの進捗を管理する
