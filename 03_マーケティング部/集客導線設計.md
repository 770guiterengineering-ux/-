# 集客導線設計

## 全体の流れ（ファネル）

```
SNS発信（X / Instagram / YouTube）
   ↓
プロフィール・固定ポスト
   ↓
無料note（入口記事）
   ↓
有料note（本命商品）
   ↓
マガジン登録 / リピート購入
```

## チャネルごとの役割

| チャネル | 役割 | 投稿頻度目安 |
|---|---|---|
| X（Twitter） | 認知拡大・日常発信・note告知 | 毎日 |
| Instagram | ビジュアル訴求・世界観づくり | 週3〜4 |
| note（無料記事） | 信頼構築・有料への導線 | 週1〜2 |
| メルマガ/公式LINE（あれば） | 濃い読者への直接オファー | 配信都度 |

## 有料note公開時の告知チェックリスト
- [ ] 公開直後にXで告知（フック＋リンク）
- [ ] 固定ポストを更新
- [ ] プロフィールリンクを最新noteに更新
- [ ] 関連する過去の無料noteからリンクを貼る
- [ ] （任意）インフルエンサー・知人に感想を依頼

## 導線改善の振り返り観点
- どのチャネルからの流入が一番購入につながったか
- 無料記事から有料記事への遷移率
- 単発購入からマガジン登録への転換率
